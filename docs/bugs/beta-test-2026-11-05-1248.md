## Critical

**BUG-01** — Cold-start redirect race (blank screen / redirect loop)
`app/_layout.tsx` lines 30–39: `router.replace('/lock')` fires before navigator is ready. Guard with `useRootNavigationState`.

**BUG-02** — PIN length mismatch — permanent lockout
`app/lock.tsx` line 140: `if (current.length < 4) return` submits at 4 digits; onboarding stores a 6-digit hash. Change to `< 6`.

**BUG-03** — "Restore from cloud" silently fails
`lib/restore.ts` requires a missing module; caller in `app/onboarding/index.tsx` swallows the error with `.catch(console.warn)`.

**BUG-04** — Onboarding sub-routes may be unresolvable on Android
`app/_layout.tsx` registers `onboarding` group only — no sub-route declarations. Verify Expo Router v4 resolves `onboarding/*`.

**BUG-05** — All data permanently empty (userId mismatch)
Hooks use `USER_ID = 'stub-user-001'`; `insertProfile` writes `userId = 'local-user'`. Every query returns empty. Export one `LOCAL_USER_ID` constant and share it.
