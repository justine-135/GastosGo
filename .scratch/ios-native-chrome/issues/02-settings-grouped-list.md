# 02: Settings grouped list restyle

**What to build:** The Settings screen rows render in iOS inset-grouped table style: rounded section corners, system background color, hairline separators, and chevron disclosure indicators. Rows are grouped into logical sections, each in a rounded container matching the iOS grouped table view convention.

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] Settings rows use inset-grouped styling: rounded corners on first/last row of each section, system-appropriate background
- [ ] Hairline separators appear between rows within a section
- [ ] Each navigable row shows a chevron disclosure indicator on the right
- [ ] Rows are grouped into logical sections (not one flat list)
- [ ] Visual appearance matches iOS Settings.app grouped table convention
